PolyMath Algebra REPL

Available Commands:

  • :help - Show this help
  • :simplify - Simplify the current expression
  • :visualize - Show expression tree (Graphviz)
  • :latex - Show LaTeX representation
  • :eval - Evaluate the expression
  • :set <var> <value> - Set a variable
  • :vars - Show all variables
  • :tree - Show text tree representation

Expression Formats:

  • Infix: 1 + 1, 2 * 3, x^2
  • Command: add 1 1, multiply 2 3
